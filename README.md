YourAITools tracks AI tools, APIs and agents you can pay with crypto, focusing on the x402 protocol and USDC. It lists 422 tools (data updated 2026-11-06) and verifies them via live unpaid calls returning HTTP 402, public listings, homepage load, and dated checks. The platform is free, offers paid fast‑track review, featured placement and sponsorship, but does not rank by payment and does not hold user funds.

**Areas:** AI · Marketplace · Crypto · x402 · Tools · Company

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for YourAITools: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
